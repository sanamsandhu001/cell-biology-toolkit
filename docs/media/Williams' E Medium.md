# Williams' E Medium

## Quick Facts

| Feature             | Information                                                       |
| :------------------ | :---------------------------------------------------------------- |
| Medium Type         | Specialized basal medium                                          |
| Original Developer  | George M. Williams                                                |
| Best For            | Primary hepatocytes and liver models                              |
| Common Applications | Drug metabolism, hepatotoxicity, liver organoids, CYP450 studies  |
| Common Supplements  | ITS, Dexamethasone, GlutaMAX/L-Glutamine, Penicillin-Streptomycin |
| Storage             | 2-8°C, protected from light                                       |

## Overview

Williams' E Medium is a specialized basal medium developed for the long-term culture and maintenance of primary hepatocytes and other differentiated liver cells. Unlike general-purpose media, it is formulated to preserve liver-specific metabolic functions rather than maximize cell proliferation, making it the gold standard for hepatocyte culture.

It is widely used in pharmacology, toxicology, liver disease research, and drug metabolism studies where maintenance of hepatic function is essential.

# Key Features

* Optimized for differentiated hepatocytes
* Preserves liver-specific metabolic functions
* Supports long-term hepatocyte maintenance
* Compatible with serum-free culture systems
* Ideal for CYP450 induction and drug metabolism studies
* Standard medium for liver toxicology research

# Typical Supplements

| Supplement               | Purpose                        |
| :----------------------- | :----------------------------- |
| ITS Supplement           | Serum-free maintenance         |
| Dexamethasone            | Maintains hepatocyte phenotype |
| FBS (initial attachment) | Cell attachment and recovery   |
| GlutaMAX™ or L-Glutamine | Nitrogen metabolism            |
| Penicillin-Streptomycin  | Antibiotic                     |
| HEPES                    | Additional buffering           |

# Liver-Specific Functional Assays

Williams' E Medium is commonly used for measuring:

* Albumin secretion
* Urea production
* Glycogen storage
* CYP450 enzyme activity
* Bile acid metabolism
* Lipid metabolism

# Advantages

* Gold standard for primary hepatocyte culture
* Preserves differentiated liver function
* Excellent for metabolism and toxicology studies
* Supports long-term maintenance

# Limitations

* Specialized for hepatic cells
* Requires supplementation
* More expensive than general-purpose media
* Not suitable for most immortalized cell lines
