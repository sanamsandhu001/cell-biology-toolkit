# L-Glutamine

| Feature                       | Information       |

| Supplement Type               | Amino acid        |

| Molecular Formula             | C₅H₁₀N₂O₃         |
| Molecular Weight              | 146.15 g/mol      |
| Typical Stock Concentration   | 200 mM            |
| Typical Working Concentration | 2 mM              |
| Storage                       | −20°C (aliquoted) |

# Overview

L-Glutamine is a conditionally essential amino acid and one of the most important nutrients in mammalian cell culture. It serves as a major carbon and nitrogen source for rapidly proliferating cells and is required for energy production, protein synthesis, nucleotide biosynthesis, and maintenance of cellular redox balance.

Although many commercial media are supplied with L-glutamine, it is chemically unstable in solution and gradually degrades into ammonia and pyroglutamate during storage. Because of this limitation, many modern protocols instead use stabilized glutamine supplements such as GlutaMAX™.

# Biological Role

L-Glutamine is essential for:

* ATP production through the TCA cycle
* Protein synthesis
* DNA and RNA synthesis
* Glutathione production
* Cell proliferation
* Nitrogen metabolism

# Typical Applications

L-Glutamine is commonly added to media for:

* Immortalized cell lines
* Primary cells
* Stem cells
* iPSC and ESC culture
* Immune cell culture
* Neuronal cultures
* Organoids
* Hybridomas
* Biopharmaceutical production

# Recommended Use

| Parameter             | Recommendation                                             |
| :-------------------- | :--------------------------------------------------------- |
| Stock Solution        | 200 mM                                                     |
| Working Concentration | 2 mM                                                       |
| Addition              | Supplement only if not already present in the basal medium |

Always verify whether the basal medium already contains L-glutamine before supplementation.

# Advantages

* Essential nutrient for mammalian cells
* Supports rapid proliferation
* Compatible with most basal media
* Cost-effective
* Extensively validated in published protocols

# Limitations

* Chemically unstable in aqueous solution
* Degrades to ammonia and pyroglutamate during storage
* Reduced stability at 37°C
* Requires fresh media preparation for optimal performance
