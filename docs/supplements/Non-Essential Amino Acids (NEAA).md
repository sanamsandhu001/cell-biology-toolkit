# Non-Essential Amino Acids (NEAA)

## Quick Facts

| Feature                       | Information                                               |
| :---------------------------- | :-------------------------------------------------------- |
| Supplement Type               | Amino acid mixture                                        |
| Composition                   | Seven non-essential amino acids                           |
| Typical Stock Concentration   | 100×                                                      |
| Typical Working Concentration | 1×                                                        |
| Primary Function              | Reduces metabolic burden and supports cell growth         |
| Common Use                    | Stem cells, primary cells, recombinant protein production |

# Overview

Non-Essential Amino Acids (NEAA) Supplement is a chemically defined mixture of amino acids added to mammalian cell culture media to improve cell growth, viability, and protein synthesis. Although mammalian cells can synthesize these amino acids, exogenous supplementation conserves cellular energy, allowing greater metabolic resources to be directed toward proliferation, differentiation, and specialized cellular functions.

NEAA supplementation is routinely included in complete media for stem cells, primary cells, recombinant protein production, and metabolically demanding cell types.

# Composition

Standard NEAA formulations contain seven amino acids:

| Amino Acid      | Primary Function                            |
| :-------------- | :------------------------------------------ |
| L-Alanine       | Energy metabolism                           |
| L-Asparagine    | Protein synthesis                           |
| L-Aspartic Acid | TCA cycle intermediate                      |
| L-Glutamic Acid | Nitrogen metabolism                         |
| Glycine         | Nucleotide synthesis                        |
| L-Proline       | Collagen and extracellular matrix synthesis |
| L-Serine        | Lipid and nucleotide synthesis              |

# Biological Functions

NEAA supplementation supports:

* Protein synthesis
* Cellular metabolism
* DNA and RNA synthesis
* Extracellular matrix production
* Cell proliferation
* Stem cell maintenance

# Typical Applications

NEAA is commonly used for:

* Human and mouse embryonic stem cells
* Induced pluripotent stem cells (iPSCs)
* Primary cell culture
* HEK293 and CHO cells
* Neural stem cells
* Brain organoids
* Hybridoma cultures
* Recombinant protein production

# Recommended Use

| Parameter             | Recommendation                                                |
| :-------------------- | :------------------------------------------------------------ |
| Stock Solution        | 100×                                                          |
| Working Concentration | 1×                                                            |
| Addition              | Supplement only if not already present in the complete medium |

Always verify whether the basal medium or commercial complete medium already contains NEAA.

# Advantages

* Reduces metabolic demand on cells
* Improves proliferation and viability
* Enhances protein synthesis
* Supports stem cell expansion
* Compatible with most mammalian culture media

# Limitations

* Not essential for all cell lines
* Benefits vary depending on cell type
* Does not replace essential amino acids
* Excess supplementation generally provides little additional benefit
