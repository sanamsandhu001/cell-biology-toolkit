# B-27™ Supplement

## Quick Facts

| Feature                       | Information                               |
| :---------------------------- | :---------------------------------------- |
| Supplement Type               | Chemically defined, serum-free supplement |
| Primary Use                   | Neuronal survival and maturation          |
| Typical Working Concentration | 1× (from a 50× stock)                     |
| Common Basal Media            | Neurobasal, Neurobasal™ Plus, DMEM/F-12   |
| Storage                       | −20°C (avoid repeated freeze-thaw cycles) |

# Overview

B-27™ Supplement is a chemically defined, serum-free supplement developed to support the long-term survival, growth, maturation, and function of neurons. It supplies essential nutrients, antioxidants, hormones, lipids, vitamins, and trace components required for healthy neuronal cultures while minimizing glial proliferation.

It is considered the gold-standard supplement for primary neuronal culture and is widely used in neuroscience, stem cell research, brain organoid culture, and neuronal differentiation protocols.

# Biological Role

B-27™ Supplement supports neuronal cultures by:

* Promoting neuronal survival
* Reducing oxidative stress
* Supporting neurite outgrowth
* Enhancing synapse formation
* Maintaining long-term neuronal health
* Enabling serum-free neuronal culture

# Typical Applications

B-27™ Supplement is widely used for:

* Primary cortical neurons
* Primary hippocampal neurons
* iPSC-derived neurons
* Neural stem cells (NSCs)
* Neural progenitor cells (NPCs)
* Brain organoids
* Cortical organoids
* Electrophysiology
* Calcium imaging
* Synaptic biology
* Neurodegenerative disease models

# Advantages

* Chemically defined formulation
* Serum-free
* Supports long-term neuronal survival
* Promotes neurite outgrowth
* Enhances synaptic maturation
* Highly reproducible
* Compatible with electrophysiology and live-cell imaging

# Limitations

* Requires a suitable basal medium
* Proprietary formulation
* More expensive than serum-based supplements
* Not intended for use as a standalone culture medium
