# Overview

The Stem Cell Marker Atlas is a consolidated reference guide for commonly used markers in stem cell biology, developmental biology, neuroscience, regenerative medicine, and disease modeling.

Markers are used to identify specific cell types, assess differentiation status, validate experimental outcomes, and annotate transcriptomic datasets.

Because no individual marker is completely specific, cell identity should always be confirmed using multiple complementary markers.

# Important Marker Caveats

| Marker | Limitation |
|----------|------------|
| GFAP | Also expressed in radial glia, reactive astrocytes and some NSCs |
| IBA1 | Also labels macrophages and activated monocytes |
| Nestin | Present in multiple neural progenitor populations |
| SOX2 | Shared by pluripotent stem cells and neural stem cells |
| CD11b | Not specific for microglia |

Always validate cell identity using **multiple complementary markers** and, where appropriate, functional assays.
